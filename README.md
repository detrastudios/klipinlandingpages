# Klipin Landing Page

Landing page untuk **Klipin**, studio video affiliate faceless dari Detra Studios.

- Satu file: `index.html` (HTML + CSS, tanpa build)
- Harga: Rp25.000 sekali beli (promo launching, harga normal Rp49.000 dicoret)
- Hitung mundur promo: ubah `PROMO_END` di bagian `<script>` paling bawah `index.html`
- Link checkout: https://winme.id/detrastudios1/klipin-ai-video-affiliate-tools
- Kredit: https://www.instagram.com/detrastudios/

## Deploy ke GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)`.

- Galeri contoh video: ganti ID video YouTube Shorts di section `#galeri` (di `href`) dan ganti gambar cuplikan di folder `assets/thumbs/` (`contoh-1.jpg` sampai `contoh-5.jpg`). Kartu membuka video di YouTube.
